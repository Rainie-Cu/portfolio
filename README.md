# 李雨桐的个人作品集

一个展示个人经历、项目实践与内容创作作品的静态作品集网站。

## 项目简介

本项目以单页网页的形式呈现李雨桐的个人信息与作品，内容涵盖嘉士伯中国与谷雨生物相关的实习项目、校园实践、社交账号运营案例，以及 AIGC 产品视频作品。网站采用响应式布局，支持作品图片放大浏览和视频弹窗播放。

## 内容模块

- 关于我与教育背景
- 实习经历：数字化转型、项目运营与招聘运营
- 项目经历：嘉士伯「嘉你主意」项目、谷雨生物项目
- AIGC 视频作品展示
- 校园经历与账号运营案例
- 技能特长与联系方式

## 技术栈

- HTML5
- CSS3
- 原生 JavaScript

## 本地预览

克隆仓库后，直接使用浏览器打开 `index.html` 即可预览。

如需通过本地服务器访问，可在项目根目录执行：

```bash
python -m http.server 8000
```

随后访问 `http://localhost:8000`。

## 目录结构

```text
.
├── index.html          # 页面主体
├── css/
```
